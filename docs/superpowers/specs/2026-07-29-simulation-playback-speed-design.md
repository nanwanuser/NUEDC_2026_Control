# 仿真固定四倍速播放设计

## 目标

将 Matplotlib 仿真的自动播放速度从实时 `1x` 提高到固定 `4x`，不改变决策、轨迹、采样数据或时间显示语义。

## 设计

- 保持动画定时器周期为 `40 ms`，维持当前界面刷新频率。
- 每次定时回调将仿真时间推进 `0.16 s`，即 `40 ms * 4`。
- 时间滑块、曲线横轴和状态栏继续显示仿真时间，不显示倍率控件。
- 播放到总时长后沿用现有逻辑，从 `0 s` 重新开始。
- 快照渲染不依赖自动播放，因此输出保持不变。

## 验证

- 定时回调一次后，当前仿真时间从 `1.00 s` 变为 `1.16 s`。
- 当前时间接近终点时，下一次回调回到 `0 s`。
- 原有 10 项仿真测试继续通过。
- 固定与通用模式快照继续成功生成。

## 非目标

- 不增加倍速滑块或模式选择器。
- 不修改 C 决策和轨迹算法。
- 不修改轨迹采样周期或运动约束。
